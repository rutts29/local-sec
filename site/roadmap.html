Safety guardrails

These constraints apply to every phase — present and future:

  • Never execute a malicious or suspected-malicious package on the host.
  • Never mount or forward a real home directory, personal files, secrets, shell history, cloud credentials, or agent transcripts into sandboxes, models, or approval messages.
  • Local Docker testing stays limited to harmless fixtures unless there is explicit approval for broader samples.
  • Dynamic malicious-package testing is deferred to disposable remote, VPS, or Mac VM environments built for detonation.
  • LLM review receives redacted evidence only. It may escalate risk or summarize — it cannot downgrade a deterministic block.
  • Local model experiments stay evidence-only; no raw secrets, host paths, or live detonation data go to a model.
