01 — How it works

Three lanes. One honest verdict.

Every install gets exactly one decision, logged on your machine. When it’s unsure, it blocks instead of allowing.

preflight→ stage→ scan→ advisory→ verdict
trusted

Install proceeds

Mature package, clean scan, clean advisories. The install continues as you asked.

risky

Review first

Too-new packages, install scripts, direct downloads, or other red flags — held for you in a local inbox.

block

Hard stop

Known malware, curl | sh, plain HTTP, credential theft patterns, or an identity that can’t be resolved.

02 — What it does

What happens before every install.

Four capabilities that keep the guard strict without getting in the way when the path is clean.

Guards npm npx pip pip3 uv uvx pipx curl wget

Doesn’t trust “latest” by default

Packages inside a 7-day publish window stay under review. Mature versions win over brand-new latest.

latestpublished 2d
matureselected ✓

Looks for dangerous behavior

Scans staged packages for credential access, unexpected network use, obfuscation, persistence, install scripts, and risky agent or editor paths.

Cross-checks known vulnerabilities

Queries OSV by default. Uses Socket and Snyk when those CLIs are already installed.

Approvals are byte-exact

You approve package + version + SHA-256 together. Different bytes never ride on an old approval.

03 — Safety & privacy

Fail-closed is the feature.

A security tool that guesses is a liability. Principles that don’t belong in a feature list.

Fails closed, always

If an advisory refresh fails with no cache, or identity can’t be resolved, the run blocks. It never degrades to “allow.”

No telemetry, ever

Does not phone home. Optional advisory lookups send only package name and version — not projects or machine details.

Secrets stay put

Inventory reads allowlisted metadata only. Evidence is redacted of secrets and host paths before any handoff leaves the machine.

05 — FAQ

Straight answers.

Only what the sections above don’t already settle.

Does local-sec change the package version I asked for?

No. It never silently installs a different version than you requested. It may prefer a mature release when you ask for latest, and it will block or queue review when the choice is unsafe — but it won’t swap versions behind your back.

Does it send data about my machine or projects?

No telemetry. Optional advisory checks send only package name and version to services like OSV.

Does it work offline?

Core guarding and scanning run locally. Advisory enrichment needs network when no cache is available — and if that refresh fails, local-sec fails closed rather than guessing.
